# API 공급자 검증 계획

PRD-01은 외부 API를 호출하지 않습니다. 아래는 PRD-04에서 검증할 후보이며 공급자 선택을 확정한 명세가 아닙니다. 원 PRD의 무료 요금과 호출 한도는 구현 시점에 다시 확인합니다.

| 기능 | 검토 후보 | 검증 항목 |
| --- | --- | --- |
| 출발·도착 대중교통 경로 | [TMAP 대중교통 API](https://transit.tmapmobility.com/) | 요금·쿼터·지원 지역, 좌표, 구간·정차·시간 근거 |
| 버스 노선·정류장·위치·도착 | [공공데이터포털 TAGO](https://www.data.go.kr/) | API별 도시 지원, 인증, 공급자 ID, 방향별 정차 순서, 갱신 주기 |
| 지하철 노선·정차·운행 패턴 | 공급자 미정 | 분기·급행·순환·회차 표현, 사용권, 날짜별 운행 |
| 장소·주소 검색 | 공급자 미정 | 좌표·ID·동명이장소 구분, 저장·캐싱·표시 약관 |

## 검증을 통과해야 하는 조건

1. 공급자 공식 문서 및 실제 인증 응답으로 지원 지역과 서비스 조건을 확인합니다.
2. 요청당 비용·일일 한도·요금제·초과 동작을 검증합니다. 승인 없이 유료 구독하지 않습니다.
3. 방향별 정류장 순서, 차량/운행 패턴, 급행 정차역을 재현 가능한 응답으로 확보합니다.
4. 장소 ID와 노선·정류장 ID 매핑의 정확성을 확인합니다. 이름 일치만으로 연결하지 않습니다.
5. 날짜·시각·갱신 지연과 실시간/시간표/추정 정보를 구분합니다.
6. 캐싱·파생 경로 생성·출처 표기 조건을 약관으로 확인합니다.
7. 네트워크·인증·한도 오류 응답을 테스트합니다.
8. 앱 UI에 실제 지원 범위와 데이터 시각을 반영합니다.

외부 API에 현재 탑승 차량 지정 기능이 있다고 가정하지 않습니다. 현재 차량에서 가능한 하차 지점과 후속 구간을 별도로 검증해야 합니다. 기능을 공식 문서에서 확인하지 못했을 때는 미확인으로 남깁니다.

키는 저장소와 APK에 넣지 않으며 비밀키가 필요한 공급자는 서버 프록시를 검토합니다. 테스트 응답에는 키·사용자 좌표·개인 이동 기록을 남기지 않습니다. Mock Provider는 명시적으로 테스트용이며 실사용 경로로 표시하지 않습니다.
