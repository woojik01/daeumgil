# PRD-01 검증

## 자동 검증

- 단위 테스트: 시스템 테마 추종과 강제 모드, 잘못된 저장값의 기본값, 실제 DataStore 파일을 닫고 다시 열었을 때 유지, 읽기/쓰기 실패와 재시도.
- Android 테스트: 홈→현재 상태/목적지/즐겨찾기→뒤로, 길 찾기 비활성화, 테마 선택과 Activity 재생성 후 설정 화면·선택값 복원.
- CI: Debug 앱·테스트 APK 컴파일, 단위 테스트, Lint, API 35 에뮬레이터 테스트.

Activity 재생성 테스트와 DataStore 재오픈 테스트는 완전한 기기 프로세스 종료 테스트와 다릅니다. 현재 버전에는 이동 안내 세션이 없으므로 PRD TEST-08 이동 세션 복원은 아직 검증 대상이 아닙니다.

## 실기기 확인 (사용자 실행 필요)

- [ ] API 26 이상 기기에 Debug APK 설치·실행
- [ ] 로그인이나 위치 권한 요청 없이 홈 표시
- [ ] 현재 상태·목적지·즐겨찾기·설정 진입과 뒤로 조작
- [ ] 라이트·다크·시스템 테마 모두 가독성 확인
- [ ] 테마 변경 후 강제 종료·재실행 시 유지
- [ ] 시스템 테마 변경 시 시스템 모드 추종
- [ ] 상태바·제스처 내비게이션·3버튼 내비게이션이 내용 가리지 않음
- [ ] 글자 크기 200%, 작은 화면, 가로 회전에서도 스크롤·버튼 조작
- [ ] TalkBack에서 카드·테마 그룹·뒤로 버튼 의미와 선택값 안내

실제 노선·목적지·경로 안내는 준비 상태입니다. 이 APK의 화면을 실제 이동 지시로 사용하지 않습니다. 실기기 결과는 자동 테스트 결과와 별도로 PR에 기록합니다.
