# PRD-02 — 현재 이동 상태 선택

기준: PRD v1.0.0. 선행 PRD-01 #2 병합 후 독립 브랜치로 구현합니다.

## 구현된 사용자 흐름

1. 홈에서 현재 이동 상태를 선택합니다.
2. 미탑승·지하철·버스·도보·택시/기타를 버튼으로 고릅니다.
3. 버스는 지역을 먼저 고릅니다. 노선 검색은 이름·번호·노선 설명을 필터링하며, 같은 번호의 노선도 공급자 노선 ID와 설명으로 구분합니다.
4. 지하철·버스는 노선과 방향을 고릅니다. 제공되는 노선에서만 일반·급행을 선택할 수 있습니다.
5. 현재 또는 마지막 통과 위치를 정류장 목록에서 선택합니다. 노선·방향·서비스 종류에 맞는 정차 지점만 표시합니다.
6. 현재 탑승 여부를 확인하고 저장합니다. 미탑승·도보·기타는 확인한 장소만 선택합니다.
7. 홈에 저장 상태와 사용자 확인 시각이 표시됩니다. 다시 선택하면 수정할 수 있으며 뒤로 돌아가면 미저장 변경을 취소합니다.

저장은 명시적인 버튼 조작으로만 합니다. 진행 방향을 모르면 `방향을 모르겠어요`를 선택해 불확실성을 저장합니다. 미확인 방향을 확인된 방향으로 자동 추정하지 않습니다. 앱 재실행 후 이전 상태가 지금도 맞는지 사용자에게 확인하도록 표시합니다.

## 데이터 범위와 제한

- 공급자는 `TransitSelectionProvider` 계약 뒤에 분리합니다. 현재 `SampleTransitSelectionProvider`만 연결합니다.
- 모든 지역·노선·정류장은 가상의 체험용 자료입니다. 홈과 입력 화면에 샘플 표시를 제공합니다.
- 샘플에는 A/B 지하철 노선, 일반·급행의 서로 다른 정차 지점, 두 지역과 동일 번호의 세 버스 노선이 있습니다. 실제 수도권 운행 정보를 의미하지 않습니다.
- 실제 장소·노선 ID·좌표·운행 패턴 검증은 PRD-03/04 범위입니다.
- 샘플 데이터 또는 방향 미확인 상태는 경로 안내에 사용할 수 없습니다. 현재 길 찾기는 계속 비활성화합니다.
- 지도, GPS 자동 판정, 실시간 위치, 경로 계산, 안내 세션 저장은 이번 단계 범위가 아닙니다.

## 상태와 검증

`CurrentTransitContext`: 수단, 공급자, 지역, 노선, 방향, 방향 미확인 여부, 서비스 종류, 정류장 ID와 정차 순번, 현재/직전 위치 구분, 탑승 확인, 사용자 확인 시각.

순번은 선택한 방향·서비스의 정차 목록을 기준으로 합니다. 방향이 미확인인 경우 특정 순번을 만들어 저장하지 않습니다. 이름만으로 버스·정류장을 연결하지 않습니다.

수단 변경 시 기존 노선 선택을 비웁니다. 지역 변경 시 노선과 후속 입력을 비웁니다. 노선·방향·서비스 변경 시 잘못된 정류장 선택과 이전 탑승 확인을 초기화합니다. 같은 선택을 다시 눌러도 유효한 입력을 지우지 않습니다.

필수 입력 누락, 다른 수단의 노선, 지역 불일치, 다른 노선의 방향, 서비스 불일치, 정류장·순번 불일치, 탑승 미확인, 비탑승 수단에 남은 노선 필드를 검증합니다. 검증 실패 시 저장하지 않고 해결해야 할 입력을 표시합니다.

## 저장·복원

- 확인된 선택: 별도 Preferences DataStore `current_transit`에 원자적으로 저장합니다. 테마 DataStore와 분리합니다.
- 편집 중 입력: 버전이 있는 문자열로 SavedStateHandle에 저장합니다. 인스턴스 상태가 복원될 때 부분 입력을 복원합니다.
- 디스크와 인스턴스 상태는 같은 codec을 사용합니다. 식별자를 Base64로 이스케이프하여 구분자·유니코드를 보존합니다.
- 저장 실패 시 이전 저장값과 편집 입력을 유지합니다. 성공한 경우에만 홈으로 돌아갑니다.
- 읽기 오류를 정상 기본값으로 숨기지 않고 오류·재시도를 제공합니다. 읽기 실패 중 저장을 차단합니다.
- 복원한 선택이 현재 공급자 목록과 불일치하면 재선택을 요청합니다. 검증되지 않은 저장값을 홈의 정상 선택으로 표시하지 않습니다.

## 검증 대상

단위 테스트: 누락·ID 불일치·정차 순번·방향 변경·급행·지역 변경·동일 번호·샘플/미확인 경로 차단, codec, DataStore 재오픈·오류, ViewModel 저장 실패·재시도·취소·부분 입력 복원.

Android 테스트: 입력 누락 안내, 도보 저장과 Activity 재생성, 지하철 부분 입력 복원과 급행 정차 목록, 버스 지역 변경과 미확인 방향 저장. 기존 화면 탐색과 테마 복원 테스트도 유지합니다.

Activity 재생성·SavedStateHandle 재구성·DataStore 재오픈은 각각 별도로 검증합니다. 자동 테스트가 전체 OS 프로세스 종료·실기기·실제 운행 검증을 대신한다고 주장하지 않습니다.
